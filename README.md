# FitPulse

Aplicación fitness simple construida con HTML, CSS y JavaScript puro.

## Funcionalidades

- Registro de sesiones (tipo, duración y calorías)
- Resumen acumulado de sesiones/minutos/kcal
- Borrado individual de sesiones (clic en un elemento)
- Persistencia local con `localStorage`
- Calculadora de IMC
- Reinicio completo de datos

## Ejecutar

Abre `index.html` en tu navegador o ejecuta un servidor estático:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
